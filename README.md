# Project 1 – College Recruitment Improvement Study

Using Python, perform an exploratory data analysis of the CCM Computing Courses Entry Surveys. Provide insights that can help the Information Technologies Department increase enrollment in computing classes.

This project cleans and analyzes the survey data to understand why students take computing classes, how they hear about CCM, which events or activities influence them, and how interest changes by age, gender, and major. It uses visualizations and findings to help guide future recruitment and messaging for the department.

## Files Included
- `Majors Survey Results - Fall 2024.csv` – Original survey data  
- `majors_survey_cleaned.csv` – Cleaned data used for analysis  
- `survey_cleaning.ipynb` – Notebook for cleaning the dataset  
- `project1_part3_analysis.ipynb` – Notebook for analysis, plots, and results
